FilesNest — Server is running

A self-hosted backup server for your Photos library. Configure users and storage with environment variables.

Get the macOS app

The client streams your Photos library to this server in the background, and shows live progress from the menu bar.

Download for macOS Requires macOS 14+

Or install with Homebrew:

Shell 
brew tap moontechs/files-nest https://github.com/moontechs/files-nest
brew trust moontechs/files-nest
brew install --cask filesnest
